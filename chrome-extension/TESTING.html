Chrome Extension - Manual Testing Guide

Note: Since this is a Chrome extension that requires browser APIs, it cannot be tested directly in this environment. Please follow the installation and testing steps below.

✅ Extension Created Successfully

The Chrome extension has been created with the following structure:

  • manifest.json - Extension configuration (Manifest V3)
  • background.js - Service worker for domain detection and session ID extraction
  • content.js - Content script running on Salesforce pages
  • popup.html/js/css - User interface
  • icons/ - Extension icons (16px, 48px, 128px)

📋 Installation Steps

  1. Open Chrome browser
  2. Navigate to chrome://extensions/
  3. Enable "Developer mode" (toggle in top right)
  4. Click "Load unpacked"
  5. Select the chrome-extension directory
  6. The extension should now appear in your extensions list

🧪 Manual Testing Steps

Test 1: Extension Icon State

  1. Open a non-Salesforce website (e.g., google.com)
  2. Expected: Extension icon should be disabled/grayed out
  3. Navigate to a Salesforce org (e.g., https://yourorg.lightning.force.com)
  4. Expected: Extension icon should be enabled/colored

Test 2: Session ID Extraction (my.salesforce.com)

  1. Log into a Salesforce org via https://login.salesforce.com
  2. Navigate to any page in your org
  3. Click the extension icon
  4. Expected: Popup should display:
    • Current domain name
    • Session ID (starting with "00D...")
    • "Open in SIID" button
    • "Copy Session ID" button

Test 3: Session ID Extraction (lightning.force.com)

  1. Navigate to a Lightning Experience URL (e.g., https://yourorg.lightning.force.com)
  2. Click the extension icon
  3. Expected: Popup should display session information
  4. The session ID should be successfully extracted from cookies

Test 4: Copy Session ID

  1. With the popup open, click "Copy Session ID"
  2. Expected: Button should change to "Copied!" with green styling
  3. Paste the clipboard content somewhere
  4. Expected: The session ID should be pasted

Test 5: Open in SIID

  1. Click the "Open in SIID" button
  2. Expected: Browser should attempt to open siid://[session-id]
  3. Note: This requires the SIID protocol handler to be installed on your system
  4. If no handler is installed, browser may show a dialog asking how to handle the protocol

✨ Key Features Implemented

  • Smart Domain Detection: Extension only activates on Salesforce domains
  • Multi-domain Support: Handles both my.salesforce.com and lightning.force.com
  • Cookie-based Session Extraction: Reads 'sid' cookie from appropriate domain
  • SIID Protocol Integration: Opens siid:// URI with session ID
  • User-Friendly UI: Clean popup with session info and actions
  • Manifest V3: Uses latest Chrome extension format

🔧 Troubleshooting

  • Extension not loading: Make sure you selected the chrome-extension directory, not a subdirectory
  • Icon not enabling: Verify you're on a *.salesforce.com or *.force.com domain
  • No session ID found: Make sure you're logged into Salesforce and have an active session
  • SIID protocol error: Install the SIID protocol handler on your system first
